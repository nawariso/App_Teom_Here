# UX/UI Guidelines

The app should feel playful, local, and mobile-native while staying readable and practical.

## Product Feel

- Friendly and collectible.
- Bangkok park identity should be visible.
- Monitor profiles should feel memorable.
- Screens should prioritize the main action over explanation.

## Navigation

Main tabs:

- Home.
- Map.
- Camera or Add Sighting.
- Ranking.
- Profile.

Detail screens can open over the main shell when they need more space.

## Key Screens

### Home

Purpose: current activity and quick entry points.

Should include:

- Recent sightings.
- Ranking preview.
- Collection preview.
- Achievement or progress preview.

### Map

Purpose: spatial discovery.

Should include:

- Bangkok-centered map.
- Park or monitor markers.
- Tap target for opening details.

### Camera/Add Sighting

Purpose: submit a sighting quickly.

Should include:

- Photo selection/capture.
- Location confirmation.
- Park confirmation.
- Submit button with clear loading/error states.

### Ranking

Purpose: compare and vote.

Should include:

- Monitor list ordered by votes.
- Vote count.
- Rarity or badge.
- Filter controls only when supported by data.

### Profile

Purpose: user progress.

Should include:

- Display name.
- Collection count.
- Level/progress.
- Collected monitors.

## Text And Localization

- Thai text must render correctly.
- English fallback text should be available where useful.
- Do not ship mojibake or corrupted emoji.
- Avoid long text inside small buttons.

## Visual System

- Use a restrained dark nature-inspired base.
- Use accent colors for rarity, action, and status.
- Keep cards compact and scannable.
- Avoid clutter on map and camera screens.

## Accessibility

- Maintain readable contrast.
- Respect touch target sizes.
- Provide empty, loading, and error states.
- Do not rely only on color to communicate rarity or state.
